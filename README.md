# Harbor — Cedar Hill School

Two versions, switched from the corner toggle.

**MVP** — family board that unifies parent communication, weekly schedule, and documents from both teachers and the office. Configure which tiles show.

**Dream** — fuller product: attendance, report cards, cafeteria, bus, classroom feed, messages.

Switch Parent / Teacher / Admin in the sidebar.
